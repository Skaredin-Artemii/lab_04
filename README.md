# Лабораторная работа №4. Алгоритмический мини-пакет (algopack)

Пакет реализует алгоритмы сортировки, структуру данных (стек), быструю степень, генераторы тестовых данных и бенчмарк для замера производительности.

## Установка и запуск

Требуется Python 3.10 или выше.

```
pip install -e ".[dev]"
```

Запуск демонстрации работы пакета и бенчмарка:
```
python -m algorithmic_package
```

## Состав пакета и анализ сложности

### 1. Рекуррентная задача: Быстрая степень
Реализованы две функции: fast_pow_iterative и fast_pow_recursive. 
- Итеративная версия: Время O(log n), Память O(1).
- Рекурсивная версия: Время O(log n), Память O(log n).
- Ограничение Python: Стандартный лимит глубины рекурсии в Python составляет 1000 вызовов. При возведении в степень больше 1000 рекурсивная версия вызовет ошибку RecursionError. Итеративная версия работает при любых значениях.

### 2. Сортировки
Реализованы две функции. Встроенный sorted() и list.sort() не используются. Исходный массив не мутирует (возвращается новый).
- Bubble Sort (Пузырьковая): Время O(n^2) в среднем и худшем случае. В лучшем случае (уже отсортированный массив) работает за O(n) благодаря флагу swapped. Память O(n) (выделяется под копию массива).
- Merge Sort (Слиянием): Время O(n log n) в любом случае. Память O(n) (выделяется под дополнительные списки при слиянии).

### 3. Структура данных: Стек (Stack)
Реализован класс Stack. 
- Методы push, pop, peek работают за Время O(1).
- Память O(n) для хранения элементов.
- При обращении к пустому стеку вызывается предметное исключение EmptyStructureError.

### 4. Генераторы
Реализовано 5 генераторов: random, sorted, reversed, nearly_sorted, duplicates. Поддерживается параметр seed для воспроизводимости. Используется random.Random(seed) для изоляции состояния.

## Benchmark

Бенчмарк сравнивает скорость работы алгоритмов сортировки.
- Методика: выполняется 5 повторов. Генерация входного массива происходит до старта таймера и не входит в замер. Для каждого запуска создается независимая копия массива, чтобы алгоритм не сортировал уже отсортированные данные. Время замеряется через time.perf_counter().
- Результаты: на 10 000 элементов Bubble Sort работает около 6 секунд, а Merge Sort — доли секунды. На 1 000 000 элементов Bubble Sort не запускался (из-за слишком долгого времени), а Merge Sort справился за ~4 секунды. Это наглядно подтверждает сложность O(n log n) у слияния и O(n^2) у пузырька.

## Тестирование

Тесты написаны с использованием pytest. Они не зависят от времени и проверяют граничные случаи (пустые массивы, дубликаты, отрицательные числа, неверные типы данных, работу параметра seed и выброс исключений). 

Запуск проверок:
```
python -m pytest
python -m ruff check .
```
